# Slovníček: obrana a dvojí užití

Klíčové pojmy, zkratky a programy z kurzu „Porozumět obraně, obchodní perspektiva" (Dr Kristýna Helm). 47 hesel v 5 tematických okruzích. Zdrojový obsah © 2025 Dr Kristýna Helm, sestaveno z kurzových materiálů Defence Hub.

> Hlubší referenční rozpad k jednotlivým tématům: export a dual-use ve složce [[01_dual-use-EU-2021-821]], certifikace v [[02_NATO-kodifikace-AQAP-NSPA]], programy v [[00_defence-hub-programy]] a [[01_EU-programy-financovani]].

## Modul 1: Regulační rámec

| Pojem | Vysvětlení |
|---|---|
| **Dvojí užití (dual-use)** | Zboží, software či technologie použitelné pro civilní i vojenské účely, podléhá kontrole vývozu. |
| **C4ISR** | Velení, řízení, komunikace, počítače, zpravodajství, sledování a průzkum, páteř moderních operací. |
| **Elektronický boj (EW)** | Využití elektromagnetického spektra k útoku, ochraně či snímání, rušení, klamání, signálové zpravodajství. |
| **Smlouva o obchodu se zbraněmi (ATT)** | Mezinárodní smlouva regulující mezinárodní obchod s konvenčními zbraněmi. |
| **Wassenaarské ujednání** | Mnohostranný režim kontroly vývozu konvenčních zbraní a zboží dvojího užití, vede kontrolní seznamy. |
| **Režim kontroly raketových technologií (MTCR)** | Neformální režim omezující šíření raket a raketových technologií. |
| **Skupina jaderných dodavatelů (NSG)** | Kontroluje vývoz jaderných a souvisejících materiálů a technologií dvojího užití. |
| **Australská skupina (AG)** | Režim kontroly vývozu bránící šíření chemických a biologických zbraní. |
| **ITAR** | Americká pravidla kontrolující vývoz a dovoz obranných položek na US Munitions List. Viz [[05_US-ITAR-EAR-a-reexport]]. |
| **Nařízení EU o dvojím užití, (EU) 2021/821** | Rámec EU vyžadující licence pro vývoz kontrolovaných položek dvojího užití, vymáhán národně. Viz [[01_dual-use-EU-2021-821]]. |
| **BAFA** | Německý Spolkový úřad pro hospodářství a kontrolu vývozu, národní vymahatel pravidel EU (český protějšek: Licenční správa MPO). |
| **Catch-all doložka** | Vyžaduje licenci i pro neuvedené položky určené ke zbraním hromadného ničení nebo citlivému užití. |

## Modul 2: Výzkum a financování (EU)

| Pojem | Vysvětlení |
|---|---|
| **Společná bezpečnostní a obranná politika (CSDP/SBOP)** | Rámec EU pro obranu a krizové řízení. |
| **Versailleská deklarace** | Závazek lídrů EU z 11. 3. 2022 zvýšit výdaje, spolupracovat a posílit průmysl včetně SME. |
| **Koordinovaný roční přezkum obrany (CARD)** | Přehled o obranném prostředí EU, synchronizuje národní plánování a rozvoj schopností. |
| **Stálá strukturovaná spolupráce (PESCO)** | Rámec pro hlubší obrannou spolupráci EU skrze společné projekty schopností. |
| **PADR** | Preparatory Action on Defence Research, předchůdce EDF, 2017 až 2019. |
| **EDIDP** | European Defence Industrial Development Programme, předchůdce EDF, 2019 až 2020. |
| **Evropský obranný fond (EDF)** | Nástroj EU podporující společný obranný výzkum a schopnosti, 8 mld. EUR na 2021 až 2027 (výzkum 2,7 / vývoj 5,3). Viz [[01_EU-programy-financovani]]. |
| **Horizon Europe** | Program EU pro výzkum a inovace (95,5 mld. EUR), klastry 3 (civilní bezpečnost) a 4 (digitál, průmysl, vesmír). |

## Modul 3: Obchod, marketing a prodej

| Pojem | Vysvětlení |
|---|---|
| **Akvizice** | Celý nákupní proces: rozhodnutí co a jak koupit a jak to operačně integrovat. |
| **Zadání zakázky (procurement)** | Užší proces správy a vyjednání smlouvy, závěrečná fáze akvizice. |
| **Jedinečná prodejní výhoda (USP)** | Jasný a obhajitelný důvod, proč zákazník zvolí vaše řešení před konkurencí. |
| **Tenders Electronic Daily (TED)** | Oficiální portál EU pro veřejné zakázky, včetně otevřených obranných tendrů. |
| **G2G / B2G** | Government-to-Government a Business-to-Government, modely prodeje běžné v obraně. |
| **NSPA** | NATO Support and Procurement Agency, spravuje tendry pro členské státy, firmy se registrují do databáze dodavatelů. Viz [[02_NATO-kodifikace-AQAP-NSPA]]. |
| **NCI Agency** | NATO Communications and Information Agency, nákup IT, program BOA (Basic Ordering Agreements). |
| **SIPRI** | Stockholmský mezinárodní institut pro výzkum míru, klíčový zdroj dat o obranných výdajích. |
| **Global Firepower Index** | Žebříček vojenské síly států, používá se k určení velikosti zákaznické základny. |

## Modul 4: Trendy a finance

| Pojem | Vysvětlení |
|---|---|
| **Prověřování přímých zahraničních investic (FDI screening)** | Státní přezkum zahraničních investic v citlivých sektorech, bariéra kapitálu v obraně. |
| **Taxonomie EU** | Klasifikace udržitelných činností EU, její výklad vedl některé instituce k vyloučení obrany. |
| **Evropská investiční banka (EIB)** | Banka EU, její Akční plán pro obranu z 2024 rozšířil podporu, s některými vyloučenými činnostmi. |
| **EDIRPA** | Akt o společném nákupu, 310 mil. EUR na podporu společného nákupu a snížení roztříštěnosti. |
| **ASAP** | Akt na podporu výroby munice, 500 mil. EUR na navýšení výroby munice v EU na 2 mil. kusů za rok do konce 2025. |
| **EDIS** | European Defence Industrial Strategy, investovat „více, lépe, společně, evropsky" a snížit závislost mimo EU. |
| **EDIP** | Program evropského obranného průmyslu, uvádí EDIS do praxe (2025 až 2027), 1,5 mld. EUR pro EU i Ukrajinu. |
| **SAFE** | Security Action for Europe, úvěrový nástroj (ReArm Europe) mobilizující až 150 mld. EUR, v platnosti od 29. 5. 2025. |
| **Defence Readiness Omnibus** | Balíček EU z 6/2025 zjednodušující zakázky, pravidla EDF, povolování a financování. |
| **EDTIB** | Evropská obranná technologická a průmyslová základna, výrobní a inovační ekosystém obrany EU. |
| **Vznikající a převratné technologie (EDTs)** | Technologie (AI, autonomie, kvantum, hypersonika a další) měnící obranné schopnosti a soupeření. |

## Expertní sezení (offsety a životní cyklus)

| Pojem | Vysvětlení |
|---|---|
| **Offsety** | Státem nařízené průmyslové kompenzační závazky připojené k obranným zakázkám. |
| **Přímý offset** | Offset přímo související s prodávaným obranným produktem (koprodukce, subdodávky). |
| **Nepřímý offset** | Offset v nesouvisející civilní či ekonomické aktivitě v zemi kupujícího. |
| **Průmyslová účast (industrial participation)** | Rozvoj místního průmyslu kupujícího skrze transfer technologií a místní obsah v rámci offsetu. |
| **Integrovaná podpora životního cyklu (ILS)** | Jednotné řízení systému po celý život (údržba, zásobování, výcvik, data, likvidace). |
| **ALP-10** | NATO Allied Logistics Publication 10, pokyny pro integrovanou podporu životního cyklu (schválila AC/327 LCMG). |

> Rozpracování offsetů a ILS jako obchodní příležitosti pro SME: [[04_offsety-a-lifecycle]].
